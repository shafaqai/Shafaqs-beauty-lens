## Inspiration
Buying skincare online is a gamble. Shoppers can't tell which products suit their skin, so they guess, and disappointment and returns follow. We wanted to give customers the confidence of an in-store skin consultation, right from their phone, and give skincare brands a simple tool to offer it.

## What it does
Shafaq's Beauty Lens analyzes a customer's skin from a single selfie, detecting concerns such as acne, dark spots, dryness and oiliness. It then recommends skincare products that match the results, all in one simple flow. Brands share it as a website link or QR code on WhatsApp, Instagram and in-store.

## How we built it
A lightweight mobile-first web app built with HTML, CSS and JavaScript, hosted on GitHub Pages. It uses the YouCam API for AI skin analysis, and a simple product list that each brand can edit. We planned the project first with a planning document and a question-first (flipped interaction) approach before writing any code.

## Challenges we ran into
Building entirely from a phone with limited resources meant keeping the app small and fast, and making the experience simple for non-technical shoppers.

## What we learned
We learned how AI skin analysis can reduce buyer uncertainty, and how important simple, mobile-first design is for everyday shoppers.

## What's next
More product categories, Shopify integration so brands can add it to their stores, and support for more languages, including Urdu.
